# Interactive Data Visualization Tools

Welcome to the repository for interactive data visualization tools. This project aims to provide custom-built interactive tools and widgets that enable users to visualize large datasets, conduct exploratory analysis, and uncover trends within the data more efficiently.

## Features
- Importing custom CSV files
- Filtering and sorting options
- Real-time graph and chart generation

## Getting Started
1. Clone this repository: `git clone https://github.com/stback2024-pixel/data-visualization-tools.git`
2. Install required dependencies (Python libraries): `pip install -r requirements.txt`
3. Run the interactive dashboard script: `python scripts/interactive_dashboard.py`
